# Synthetic Data Disclaimer

> [!IMPORTANT]
> **Synthetic Demonstration Dataset — Not Real Customer Data**

This repository contains a synthetically generated financial dataset created purely for educational, demonstration, portfolio, and analytical development purposes.

- **No Real PII**: None of the customer profiles, transactions, financial amounts, or entity IDs correspond to any real individuals or financial institutions.
- **Reproducibility**: The dataset is deterministically generated using Python (`numpy` and `pandas`) with a fixed seed (`random_seed: 42`).
- **Realistic Statistical Correlations**: While synthetic, the data incorporates domain-informed statistical distributions and correlations (e.g. income scaling with education level, credit scores reflecting payment history and debt utilization, expense distributions matching city tier cost-of-living) to enable meaningful analytical modeling, SQL queries, and Power BI visualization.
